# Facial-Emotion-Recognition
Facial Emotion Recognition using Deep Learning — detects human emotions from facial images/video in real-time using CNN.

## Dataset
A balanced facial expression dataset (7 emotion classes: Angry, Disgust, Fear, Happy, 
Neutral, Sad, Surprise) was used for training this model. Original public source was 
not tracked, so the dataset has been mirrored here for reproducibility:

📦 [Download Dataset](https://drive.google.com/file/d/1QncxXaEbd-twTKmbMuWjLTMwfGNKjZQT/view?usp=sharing)

To train the model yourself, download and extract the zip, then organize it into 
`train/`, `val/`, and `test/` folders (one subfolder per emotion class).
